# Motion Story Video v5: Creative Director

This branch contains the updated skill, a visually distinct sample video, and a single combined download.

## Files

- [Complete v5 ZIP](./motion-story-video-v5-creative-director-bundle.zip) — skill, MP4, treatment, direction record, storyboard, and sample renderer.
- [Skill only](./motion-story-video-v5.skill) — import this file through your AI client's **Import/Add skill** action.
- [Sample video](./creative-director-sample.mp4) — 21.5 seconds, 1280×720, 30 fps, H.264/AAC.

## Install

1. Download `motion-story-video-v5.skill` or the complete ZIP.
2. In your AI client, open the skill manager and choose **Import/Add skill**.
3. Select `motion-story-video-v5.skill`.
4. If your client expects a folder, unzip the `.skill` file and import the contained `motion-story-video/` folder.

A browser can download a skill but cannot silently install a local skill.
